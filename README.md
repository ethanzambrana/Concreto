# CONCRETO

Sitio web para presentar las aplicaciones de cálculo estructural de CONCRETO, facilitar la consulta de recursos técnicos y conectar a los usuarios con los canales de asesoramiento y licencias.

**[Ver sitio publicado](https://concreto-zeta.vercel.app/)**

## Funcionalidades del sitio

- Presentación y comparación de cuatro aplicaciones: Prediseño de Edificios, Calculadora de Elementos, Muro de Contención y Detalles Constructivos.
- Fichas de producto con capturas y demostraciones.
- Biblioteca de recursos técnicos y documentos de consulta.
- Videoteca con tutoriales y enlaces a contenido externo.
- Enlaces de contacto por WhatsApp para consultas y activación de licencias.

## Tecnologías

HTML, CSS y JavaScript. El sitio publicado se aloja en Vercel.

## Organización del repositorio

- `CalculadoraElementos/`, `MuroContencion/` y `PredisenoEdificio/`: archivos asociados a las aplicaciones.
- `Documentos/`: recursos técnicos.
- `Fotos/`: material visual.
- `api/`: código de servicios del sitio.
- `ADMINISTRACION.md`: documentación de administración.

## Alcance

Este repositorio presenta el sitio y sus recursos. La información comercial sobre las aplicaciones está disponible en la web publicada. Esta documentación describe la presentación web; no constituye una validación de los cálculos de ingeniería de las aplicaciones.
